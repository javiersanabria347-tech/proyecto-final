# Proyecto Final

Página sobre la historia de las computadoras con una línea del tiempo que abre experiencias web interactivas.

🌐 **Ver la página web:** [Máquinas del tiempo](https://javiersanabria347-tech.github.io/proyecto-final/)

## Cómo abrir

Abre `index.html` en un navegador para recorrer la cronología y leer el contenido. La sección de Freedoom cambia según el dispositivo:

- En celular, el juego Freedoom Phase 2 de [SFHS Doom](https://falloutmule.github.io/sfhs-doom/) se carga dentro de la página con controles táctiles; requiere internet. Pulsa «Start Fullscreen» para empezar.
- En PC, el botón de inicio abre [Dwasm](https://dwasm.m-h.org.uk/) en otra pestaña. Selecciona «Freedoom Phase 2» si hace falta. Los controles táctiles son opcionales y deben quedar desmarcados; F1 muestra la ayuda y en Options/Setup se pueden configurar las teclas WASD. Esta página externa no permite insertarse en un `iframe`.

Los controles del reproductor móvil pertenecen al sitio externo y no se pueden reorganizar desde este proyecto. Ambos juegos usan contenido original de Freedoom; no se incluyen el DOOM comercial ni sus recursos. Freedoom y los motores conservan sus licencias propias; consulta los [créditos y licencias del proyecto SFHS Doom](https://github.com/falloutmule/sfhs-doom/blob/main/docs/licenses/THIRD_PARTY_INVENTORY.md). Archivo/Pixel no está afiliado con ni respaldado por dichos proyectos.

Pulsa las bolas de 1946, 1973 o 1975 para mostrar la imagen y la explicación de ENIAC, Xerox Alto o Altair 8800. Las otras épocas abren directamente sus experiencias web: 1984 abre Macintosh System 1.0, 1995 abre Windows 95, 2026 abre Windows 11 y 2001 abre Windows XP.

Las imágenes se sirven desde Wikimedia Commons y requieren internet:

- ENIAC: “Classic shot of the ENIAC”, foto del Ejército de EE. UU., dominio público: [fuente](https://commons.wikimedia.org/wiki/File:Classic_shot_of_the_ENIAC.jpg).
- Xerox Alto: foto de Steve Jurvetson, CC BY 2.0: [fuente](https://commons.wikimedia.org/wiki/File:The_1973_Alto_Computer_at_Xerox_PARC_(52342993062).jpg).
- Altair 8800: foto de Dr. Bernd Gross, CC BY-SA 4.0: [fuente](https://commons.wikimedia.org/wiki/File:Altair_8800-Computer.jpg).

Los sitios externos de la línea del tiempo también requieren conexión a internet.
